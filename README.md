# Volume-Step
Расширение для Chrome и Яндекс Браузера: стрелки ↑/↓ на YouTube меняют громкость на 1% вместо стандартных 5%. Свой шаг от 1 до 100%, минималистичное окно настроек со светлой и тёмной темой, компактный индикатор громкости поверх видео. Без сбора данных, без рекламы, открытый код, бесплатно. Установка вручную за минуту, инструкция в README.
